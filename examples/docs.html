TYPED ESM LOADER

From Blockbench
to a moving scene.

Load the project you authored—not a reduced export. The result keeps its UUIDs, textures, skeleton, elements, clips, effects, and source metadata.

Install

npm install three three-blockbench

Load a model

import * as THREE from "three";
import { BBModelLoader } from "three-blockbench";

const model = await new BBModelLoader().loadAsync(
  "/models/desert_dog.bbmodel"
);

scene.add(model.scene);
const mixer = model.createMixer();
model.createAction(mixer, "animation.idle").play();

// In your render loop:
mixer.update(delta);
model.update(delta);

Linked texture paths resolve relative to the `.bbmodel` URL. Embedded data URLs work without extra requests.

Use UUID-indexed native objects

groups→Map<UUID, Bone>
elements→Map<UUID, SkinnedMesh>
textures→Map<UUID, Texture>
animations→AnimationClip[]
const head = model.bones.get("group-uuid");
const body = model.elements.get("element-uuid");

console.log(model.skeleton, model.document.display);
console.table(model.warnings);

AnimationMixer, without translation code

Position and scale become vector tracks. Rotation becomes quaternion tracks. Mixed linear, step, Catmull-Rom, and Bézier segments are sampled at the authored timeline rate.

const walk = model.createAction(mixer, "animation.walk_forward");
walk.reset().fadeIn(0.2).play();

Stay in control at engine boundaries

new BBModelLoader(undefined, {
  unitScale: 1 / 16,
  animationSampleRate: "snapping",
  maxAnimationSampleRate: 120,
  strict: false,
  expressionEvaluator(expression, context) {
    return molang.evaluate(expression, context);
  },
  textureFactory: async ({ url }) => texturePipeline.load(url),
  materialFactory: (context) => makeGameMaterial(context),
});

Supported project data

  • GeometryCubes, box/per-face UV, mesh polygons, inflation, stretch, pivot rotation
  • RigNested groups, multiple roots, element animation pivots, rigid skin weights
  • TextureEmbedded/linked images, layers, render modes, sides, animated atlases
  • TimelineAll transform channels and interpolation modes, effects, compatibility axes
  • MetadataDisplay transforms, collections, controllers, variable placeholders
